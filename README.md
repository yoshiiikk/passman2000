# passman2000
a very simple password "manager" that creates a 16 digit password based on 3 types of characters:
-numerical and special characters
-lowercased letter
-uppercased letters
you can find the.exe file that does it by default or you can just change the .py file to your taste
important to notice that is 100% random so it can make a password of only one type of character or a really easy password (0123456789abcdef)
also remember that It DOES NOT encrypt the password, it just creates a .txt file with them
